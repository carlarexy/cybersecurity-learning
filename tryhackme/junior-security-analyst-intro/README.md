# TryHackMe — Junior Security Analyst Intro

## 📌 Overview

This folder documents my learning journey through the **Junior Security Analyst Intro** room on [TryHackMe](https://tryhackme.com/).

The room introduced me to the role of a **Junior Security Analyst** and provided an overview of how entry-level security analysts contribute to protecting an organization's systems, networks, and data.

I also learned about the **Security Operations Center (SOC)** environment, security alert monitoring, investigation, escalation, and the importance of continuous learning in cybersecurity.

This room is part of my broader cybersecurity learning journey as I work toward developing practical skills in **SOC operations and defensive security**.

---

## 🎯 Learning Objectives

Through this room, I aimed to:

- Understand the role and responsibilities of a Junior Security Analyst
- Learn how a Security Operations Center operates
- Understand the different roles within a SOC
- Learn how security alerts are monitored and investigated
- Understand the importance of alert triage and escalation
- Gain an introduction to the day-to-day activities of a security analyst
- Connect cybersecurity theory with practical security operations
- Identify the technical and professional skills I need to continue developing

## 🧠 Key Areas Covered

### Junior Security Analyst

I was introduced to the responsibilities of a Junior Security Analyst, including monitoring security alerts, investigating suspicious activity, documenting findings, and escalating incidents when necessary.

### Security Operations Center (SOC)

I learned how a SOC provides a central environment for security monitoring, analysis, incident response, and collaboration between security professionals.

### Security Alerts & Investigation

The room introduced me to the process of reviewing security alerts and determining whether activity is legitimate, suspicious, or potentially malicious.

### Escalation

I learned that more complex security incidents may need to be escalated to more experienced analysts or specialized security teams.
